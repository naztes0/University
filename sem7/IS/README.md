# Charging Stations Monitoring

Інформаційна система для моделювання роботи мережі зарядних станцій і моніторингу навантаження на PostgreSQL.

Оператор може авторизуватися, налаштувати кількість станцій, частоту та тривалість генерації, запустити навантаження і переглядати стан системи. Застосунок записує показники станцій у PostgreSQL, а Grafana відображає метрики, логи та трейси роботи системи.

## Технології

- **Python, FastAPI** — API, генератор навантаження та сервер авторизації.
- **PostgreSQL** — основна база даних показників зарядних станцій.
- **SQLite** — збереження користувачів і сесій авторизації.
- **Prometheus та PostgreSQL Exporter** — збір і збереження метрик застосунку та БД.
- **Grafana** — дашборд для перегляду метрик, логів і трейсів.
- **Grafana Alloy та Loki** — збирання і збереження структурованих логів.
- **OpenTelemetry, Grafana Alloy та Tempo** — формування, передавання і збереження трейсів.
- **Nginx** — єдина точка входу та перевірка авторизації перед доступом до застосунку і Grafana.
- **Docker Compose** — запуск і взаємодія всіх сервісів.

## Запуск

Необхідно встановити та запустити Docker Desktop.

1. Створити локальний файл конфігурації:

   ```bash
   cp .env.example .env
   ```

2. Замінити тестові паролі у `.env` на власні. Дані для входу задаються змінними `AUTH_ADMIN_USERNAME` і `AUTH_ADMIN_PASSWORD`.

3. Зібрати та запустити систему:

   ```bash
   docker compose up -d --build
   ```

4. Відкрити у браузері:

   ```text
   http://127.0.0.1:8080
   ```
